# easy_factions (port sources)

The NeoForge 1.21.1 port of Easy Factions belongs in this directory.

The port was carried out by a collaborator and those sources are being collected from them for publication. They are not yet in this repository.

Upstream Easy Factions, by OverWatter, is at https://github.com/kard3n/easy_factions and is the origin of all code under the `com.jpreiss.easy_factions` package. Upstream is licensed under the Mozilla Public License 2.0, and this port keeps that license.
